# Design — Confraria

Inspirada no hero da Hotmart FIRE (vídeo em tela cheia, títulos condensados enormes, cartões de ingresso, lista com linhas) com a identidade DocFounder.

## Cores (tokens do projeto Framer)
Preto `#060A09` · Verde profundo `#0A2420` · Verde DocFounder `#133A32` · Lima destaque `#B5F23D` · Branco.

## Tipografia
Barlow Semi Condensed (itálico 800, caixa alta) para títulos e números; Barlow para textos.
Escala: Hero 132 / H2 76 / H3 34 / números 88–70 / lead 22 (reduz em tablet e celular via breakpoints dos estilos de texto).

## Estrutura
Hero com vídeo de fundo → VSL → faixa → dores → programação → números → edição anterior → ingressos → Thiago Moura → patrocinadores → FAQ → CTA final → rodapé. Botão flutuante de WhatsApp (só ícone no celular).

## Regras de conteúdo
- Nenhuma imagem de drone (abertura e trecho do meio foram cortados dos vídeos).
- Números da seção "Dores" informados pelo time DocFounder.
